# 交易研究可视化与交付 Playbook

## 图表原则

图表必须来自已经核验的数值，并回答明确问题：

| 问题 | 图型 |
|---|---|
| 价格趋势和关键转折 | line |
| 四维评分、多空权重、风险评分 | bar |
| 情景目标、入场与止损阶梯 | bar |
| 分阶段团队流程 | Mermaid |

每张图标注标题、单位、数据期和来源。预测或情景价格必须显著标为“情景”，不能与历史价格混写。

## 建议图表

1. 近 60 个交易日收盘价；
2. 技术/基本面/新闻/情绪评分；
3. 多头与空头核心论点权重；
4. 激进/保守/中性/风险主管评分；
5. 当前价、入场、止损和 T1/T2/T3；
6. 团队决策流程 Mermaid。

可靠数据不足时少画图，不得补齐虚构数列。

## Markdown 结构要求

- 一级标题只出现一次；
- 决策卡片使用表格，包含方向、信心、风险、仓位、入场、目标、止损；
- 评分表使用 0–10，列明结论与证据日期；
- 正文先写“所以什么”，再写证据；
- 关键数字邻近位置放来源；
- 使用相对图片路径 `assets/<文件>.png`；
- 保留信息缺口、研究局限性和非投资建议。

DOCX 与 PDF 必须从同一 Markdown 生成，保证正文、表格与图表一致。
